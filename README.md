# Comprobación de mayoría de edad en Java

En el archivo `reto.java` hemos creado un pequeño ejercicio que comprueba si una persona es mayor de edad.

El programa:

1. Guarda la edad de la persona en la variable `edad`.
2. Utiliza una estructura condicional `if-else` para comprobar si la edad es mayor o igual que 18.
3. Muestra `Mayor de edad` cuando se cumple la condición o `Menor de edad` en caso contrario.

Con el valor actual (`edad = 20`), el resultado es:

```text
Mayor de edad
```

Este ejercicio nos permite practicar variables, condiciones y la impresión de mensajes por consola en Java.
